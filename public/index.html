THE LAST WORD

Opinion is a gate.
Evidence is the key.

Security and QA are independent sign-offs. Then a deterministic verifier runs the target project's real checks. An agent saying “looks good” cannot substitute for a passing command.

01 / SECURITYGATE

Separate risk review.

Checks the risk-bearing paths for secret exposure, input handling, and reliable duplicate protection.
